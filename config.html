LLM AI — Configuration

Adresse de l'API Ollama (ex. http://192.168.11.2:11434).
Modèle à utiliser (ex. gemma4:latest).
Prompt système envoyé au LLM (role: system) à chaque appel.
Format : « <planification> | <prompt de tâche> ». Planification : Daily HH:MM, Hourly, Weekly <Day> HH:MM, Interval <heures>. La partie après le « | » est le prompt utilisateur envoyé au LLM. Déclenchable manuellement dans « Tâches planifiées ».
